# e4steam 0.3.2-beta.5-sync.3

Ветка содержит исходники ядра и Public Servers beta.12 (`addons/e4steam-public-servers`).

Современные сборки включают Addon API 1.2, проверку аддонов перед входом, повтор согласования Steam-каналов и исправление доступа к клиентскому Steam runtime из общего API. Это позволяет AeroSync предложить недостающие моды до игрового подключения.

Полный набор ядра: Fabric 1.14.x–1.16.x; Fabric/Quilt 1.17–1.18.2, 1.19–1.21.11, 26.1–26.3; Forge 1.7.x–1.16.x, 1.17.1–1.18.1, 1.18.2–1.20.2; NeoForge 1.20.2–26.3. Это диапазоны сборок, а не утверждение о ручном игровом тесте каждого патча Minecraft.

Retro использует отдельный runtime. Наличие номера sync.3 на его JAR не означает поддержку современной синхронизации AeroSync. Для Forge 1.7.x требуется отдельный UniMixins 0.1.20 или новее.

Сборка ядра: JDK 21, `./gradlew releaseJars`. Проверка Public Servers: JDK 25, из `addons/e4steam-public-servers` запустить `./gradlew verification releaseArtifactAudit`; для старых модулей также нужен JDK 17. Сборки публикуются как prerelease.

Известное ограничение: современный preJoin ждёт до десяти минут. Очень долгая загрузка модов может завершиться разрывом сессии. Полный игровой тест всех вариантов с двумя Steam-аккаунтами не выполнен.

В публичные исходники не входят игровые файлы, локальные ключи, кэши и инструменты агента.
